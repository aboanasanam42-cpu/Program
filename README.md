## ✨ المميزات الرئيسية (Core Features)

### 1. واجهة ثلاثية الأبعاد ناعمة (3D Soft / Claymorphism Design)
- بطاقات دائرية الحواف (28dp) مع ظلال مزدوجة ناعمة وحواف بارزة تعطي مظهر الصلصال الأنيق.
- خلفية رياضية ناعمة بتدرجات الباستيل مع علامات مائية لمعادلات ورموز رياضية ($y = mx + b$ ، $\Sigma$ ، $x^2$ ، $\sqrt{x}$).
- دعم كامل وتلقائي للغة العربية والاتجاه من اليمين إلى اليسار (**RTL Native Support**).

### 2. الأقسام الأربعة التفاعلية (The 4 Interactive Modules)

#### 🔺 1. تشابه المثلثات (Triangle Similarity)
- **حساب الأضلاع ومعامل التشابه ($k$):** إيجاد الضلع المجهول في مثلثين متشابهين، وتحديد نوع التحويل (تكبير / تصغير / تطابق).
- **نسب المحيطات والمساحات:** حساب نسبة المحيطين ($k$) ونسبة المساحتين ($k^2$).
- **فحص التشابه بحالة الأضلاع الثلاثة (SSS):** مقارنة أطوال أضلاع مثلثين بالترتيب والتحقق من تناسبها خطوة بخطوة.

#### ⚖️ 2. التناسب (Proportions)
- **حل معادلة التناسب العادية ($A / B = C / D$):** إدخال 3 قيم وترك القيمة الرابعة فارغة لحساب المجهول عبر ضرب الطرفين في الوسطين ($A \times D = B \times C$).
- **التناسب الطردي والعكسي:** حساب المتغير الجديد مع استنتاج ثابت التناسب ($k$) وتوضيح القانون رياضياً.

#### ➗ 3. النسبة (Ratios)
- **تبسيط النسبة ($A : B$):** إيجاد القاسم المشترك الأكبر (ق.م.أ / GCD) وقسمة حدي النسبة عليه للوصول لأبسط صورة، مع التحويل لكسر عادي ونسبة مئوية (%).
- **التقسيم التناسبي:** توزيع مبلغ مالي أو كمية إجمالية على حصص طرفين أو ثلاثة أطراف، مع حساب قيمة الجزء الواحد وحصة كل طرف والتحقق بالجمع.

#### 🧮 4. الأسس والجذور (Exponents & Radicals)
- **حساب القوى والأسس ($a^n$):** دعم الأسس الموجبة، الصفرية، والأسس السالبة ($a^{-n} = 1/a^n$) مع التفسير العلمي.
- **تبسيط الجذور التربيعية ($\sqrt{N}$):** تحليل العدد واستخراج أكبر مربع كامل خارج الجذر (مثال: $\sqrt{72} = 6\sqrt{2}$).
- **قوانين الأسس:** تطبيق قانون ضرب الأسس (جمع الأسس)، قسمة الأسس (طرح الأسس)، وقانون قوة القوة (ضرب الأسس).

### 3. المشاركة الفورية عبر واتساب (WhatsApp Sharing)
- حقل إدخال لرقم المستلم مع إمكانية إدخال الأرقام بالصيغة الدولية (`+967...` أو الصيغة المحلية).
- زر **"إرسال عبر واتساب"** يولد رسالة رياضية منسقة بوضوح تحتوي على المسألة، خطوات الحل الكاملة، النتيجة النهائية، وحقوق المبرمج.

### 4. تصدير مستندات PDF الاحترافية (PDF Export)
- تصدير تقرير رياضي عالي الدقة بحجم A4 قياسي عبر محرك `android.graphics.pdf.PdfDocument`.
- يحتوي الملف على ترويسة DR/MALIK، جدول المعطيات، خطوات الحل، صندوق النتيجة النهائية الخضراء، والخاتمة الإلزامية الدائمة.
- متوافق تماماً مع سياسات الأمان والتخزين لنظام أندرويد 15 عبر `FileProvider`.

## 🔐 جدول المتغيرات السرية في GitHub Actions (Secrets)

لتشغيل خط إنتاج النسخة الموقعة (Signed Release APK) على GitHub Actions، توجه إلى إعدادات المستودع:
`Settings` ➔ `Secrets and variables` ➔ `Actions` ➔ `New repository secret`

| اسم المتغير السري (Secret Name) | الوصف | مثال |
| :--- | :--- | :--- |
| `KEYSTORE_BASE64` | ملف مفتاح التوقيع مشفر بصيغة Base64 | `base64 -w 0 upload-keystore.jks` |
| `STORE_PASSWORD` | كلمة مرور مخزن المفاتيح (Keystore Password) | `********` |
| `KEY_PASSWORD` | كلمة مرور المفتاح الخاص (Key Password) | `********` |
| `KEY_ALIAS` | الاسم المستعار للمفتاح (Alias) | `upload` |

> *ملاحظة:* إذا لم تكن هذه الأسرار متوفرة، فإن سير العمل المبرمج يقوم تلقائياً ببناء وتصدير الـ APK بنجاح لتنزيله فوراً دون توقف الخط.

## 💻 أوامر Git لرفع التحديثات وبدء البناء الآلي (Git Commands)

نفذ الأوامر التالية في سطر الأوامر (Terminal) لدفع التحديثات وتشغيل الـ Pipeline:

```bash
# 1. فحص حالة الملفات المعدلة
git status

# 2. إضافة جميع الملفات الجديدة وإعدادات سير العمل
git add .

# 3. حفظ التغييرات برسالة واضحة
git commit -m "feat: complete DR/MALIK math app with 3D soft UI, solvers, PDF export, WhatsApp sharing, and GitHub Actions APK build"

# 4. رفع الكود إلى الفرع الرئيسي على GitHub
git push origin main
```
*(أو استبدل `main` بـ `master` إذا كان اسم فرعك الافتراضي هو master).*

## 🚀 متابعة بناء التطبيق وتحميل الـ APK (Download from GitHub Actions)

بمجرد تنفيذ أمر `git push`:
1. افتح مستودع المشروع على موقع **GitHub**.
2. اضغط على تبويب **Actions** في الشريط العلوي.
3. ستلاحظ بدء تشغيل سير العمل باسم **"Build Android Release APK (Android 15)"**.
4. اضغط على مسار العمل الجاري لمتابعة سجلات البناء خطوة بخطوة.
5. بمجرد ظهور علامة الصح الخضراء (**Green Checkmark ✅**):
   - انزل لأسفل الصفحة إلى قسم **Artifacts**.
   - ستجد ملف الـ APK جاهزاً للتحميل المباشر باسم:
     `DR_MALIK_Math_APK_v1.0` (يحتوي على `app-release.apk`).
   - اضغط على الاسم ليتم تحميل التطبيق مباشرة إلى جهازك لتثبيته واختباره على أي هاتف يعمل بنظام أندرويد.
